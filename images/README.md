# Image attribution

Photographs are downloaded from Wikimedia Commons. See [credits.json](credits.json) for the original file page, creator, individual license, license URL, and modifications. Each photograph retains its own license. The website exposes attribution per photograph. Representative family images are explicitly flagged in the catalog and UI; their alt text identifies the actual depicted hardware. Verify the source file page before changing a representative flag. Run `NODE_USE_SYSTEM_CA=1 node scripts/fetch-images.mjs` to reproduce downloads (requires network access).
